Happy Money / Verification / 2026

From document upload to intelligent verification.

Uploading the file was only the first step. With Gemma 4.0, the verification flow can classify an uploaded document and determine whether it should be accepted, rejected, or sent forward for additional review.

At a glance

The problem
The upload was treated as the end of the step. Every submission still waited for an operations team to review it.
Why it mattered
Applicants heard back late, after the moment they had already sent the file.
My role
Lead designer on verification. I framed where a model can take a first pass, and where a person still needs to decide.
What I changed
A path that can classify a document at upload and accept it, reject it, or send it on for review.
The result
A faster first pass, and a path toward real-time feedback, with manual review still in the loop.
RoleLead designer
Timeframe2026
TeamProduct / Eng / Verification ops
OutcomeReal-time verification

01 / The situation

Uploading the file was only the first step.

The document arriving was never the end of verification.

Applicants sent a file, then waited while an operations team reviewed every submission. The delay sat between the upload and any answer.

02 / The opportunity

Classification can happen as the file is submitted.

Accept, reject, or send it forward.

With Gemma 4.0, the verification flow can classify an uploaded document and determine whether it should be accepted, rejected, or sent forward for additional review. That creates an opportunity to give applicants feedback much earlier in the process instead of waiting for an operations team to review every submission.

03 / The boundary

Manual review still matters.

Especially for documents the system cannot confidently resolve.

The model gives a faster first pass and creates a path toward real-time feedback. The goal isn’t to remove people from verification. It’s to use automation where it can help, and reserve manual review for the places that actually need it.

04 / What this opens

Real-time verification.

Real-timeVerification

AI-assisted classification at upload. Gemma 4.0 can classify, accept, or reject documents as they’re submitted, creating a path toward immediate applicant feedback while keeping manual review in the loop.

In hindsight

The goal isn’t to remove people from verification. It’s to use automation where it can help, and reserve manual review for the places that actually need it.
